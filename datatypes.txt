JavaScript Data Types 
JavaScript has 8 data types. They are divided into Primitive and Non-Primitive (Reference) data types.

1. Primitive Data Types (7)

Primitive data types store a single value and are immutable.

Data Type	                    Description	Example
Number	            Represents integers and floating-point numbers	10, 3.14
String	            Represents text	"Hello"
Boolean	            Represents true or false	true, false
Undefined	        Variable declared but not assigned	let x;
Null	            Represents an intentional empty value	null
BigInt	            Represents very large integers	12345678901234567890n
Symbol	            Represents a unique identifier	Symbol("id")
