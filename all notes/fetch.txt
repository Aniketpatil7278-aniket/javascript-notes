
=-==-----------------------------fetch---------------------
The fetch() method returns a Promise that resolves to a Response object.

The Fetch API is a built-in JavaScript API used to send HTTP requests to a server and receive responses.
 It returns a Promise.

 fetch(url)


 example 


 fetch("https://jsonplaceholder.typicode.com/users")
.then((response)=>{
    return response.json();
})
.then((data)=>{
    console.log(data);
})
.catch((error)=>{
    console.log(error);
});


fetch("https://jsonplaceholder.typicode.com/users",{

    method:"POST",

    headers:{
        "Content-Type":"application/json"
    },

    body:JSON.stringify({

        name:"Aniket",

        age:24

    })

})
.then(response=>response.json())
.then(data=>console.log(data))
.catch(error=>console.log(error));



| Property            | Description                              |
| ------------------- | ---------------------------------------- |
| response.status     | HTTP status code (200, 404, 500, etc.)   |
| response.ok         | `true` if status is 200–299              |
| response.statusText | Status message (e.g., "OK", "Not Found") |
| response.headers    | Response headers                         |


Common HTTP Status Codes
| Code | Meaning               |
| ---- | --------------------- |
| 200  | OK                    |
| 201  | Created               |
| 204  | No Content            |
| 400  | Bad Request           |
| 401  | Unauthorized          |
| 403  | Forbidden             |
| 404  | Not Found             |
| 500  | Internal Server Error |
